Que faire ?

  1. Vérifiez que la première installation a bien été lancée sur /setup
  2. Consultez les logs d'erreur: storage/logs/laravel.log
  3. Assurez-vous que:
    • Les permissions des répertoires sont correctes (chmod -R 775 storage bootstrap/cache)
    • La base de données est créée et accessible
    • Les migrations ont été exécutées
    • APP_KEY est défini dans .env
  4. Si le problème persiste, essayez:
    • php artisan cache:clear
    • php artisan config:clear
    • composer dump-autoload
